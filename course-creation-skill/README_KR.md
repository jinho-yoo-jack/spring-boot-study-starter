# 강의 교안 제작 스킬 (Course Creation Skill) v3.0

## 🆕 주요 업데이트: Balanced Learning Approach

이론과 실습의 **완벽한 균형**을 추구하는 교안을 생성합니다. 50:50 비율로 깊은 이해와 실용적 적용을 동시에 달성합니다.

### 📊 콘텐츠 비율 최적화
```
v1.0 (코드 중심)    →  v2.0 (이론 중심)    →  v3.0 (균형)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
코드: 70%           →  이론: 60%          →  이론: 50%
설명: 30%           →  코드: 40%          →  코드: 50%
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 핵심 철학: "이해와 적용의 균형"

프로그래밍 교육을 위한 체계적인 교안 제작 스킬입니다. **깊은 이해**를 바탕으로 한 **의미 있는 학습**을 추구합니다.

## 주요 기능

### 🎯 7단계 Theory-First 프로세스

1. **요구사항 분석** - 학습자의 배경과 목표 심층 분석
2. **커리큘럼 설계** - 개념적 이해를 중심으로 한 구조화
3. **이론 콘텐츠 개발** - 역사, 원리, 맥락을 포함한 상세 설명
4. **코드 예제 작성** - 이론을 뒷받침하는 실습 자료
5. **평가 설계** - 이해도 측정 중심의 평가
6. **전달 최적화** - 점진적 심화 학습 경로
7. **품질 보증** - 설명의 충실도와 정확성 검증

## 생성되는 산출물

### 📚 핵심 문서

1. **강의 계획서 (Syllabus)**
   - 과정 개요
   - 주차별 학습 내용
   - 평가 방법

2. **모듈별 교안**
   ```
   Module_1_기초/
   ├── README.md          # 모듈 개요
   ├── lectures/          # 강의 자료
   ├── exercises/         # 실습 문제
   ├── solutions/         # 해답
   └── assessments/       # 평가 자료
   ```

3. **프로젝트 가이드**
   - 단계별 프로젝트 명세
   - 스타터 코드
   - 평가 기준표

### 💻 코드 자료

- **예제 코드**: 개념별 완전한 예제
- **실습 템플릿**: 학생용 스타터 파일
- **해답 저장소**: 강사용 정답 코드
- **테스트 스위트**: 자동 채점용 테스트

### 📊 시각 자료

- **다이어그램**: Mermaid 형식 플로우차트
- **인포그래픽**: 핵심 개념 요약
- **치트시트**: 문법 및 패턴 요약표

## 특징

### ✅ v3.0의 핵심 장점

1. **균형잡힌 학습**: 이론 50%, 실습 50%의 최적 비율
2. **6가지 핵심 설명**: 간결하면서도 완전한 개념 설명
3. **실용적 접근**: 이론을 바로 코드로 확인
4. **명확한 구조**: 체계적이고 일관된 설명 프레임워크
5. **즉시 적용 가능**: 배운 내용을 바로 실습

### 🎯 6-Point Framework (모든 기술 개념 필수)

#### 간소화된 핵심 설명 체계
1. ✅ **정의**: 명확하고 간결한 정의
2. ✅ **특징**: 핵심 특성 4가지
3. ✅ **왜 사용하는가**: 구체적 이점과 사용 시나리오
4. ✅ **일상생활 비유**: 쉽게 이해할 수 있는 비교
5. ✅ **작동 원리**: 단계별 동작 과정
6. ✅ **대안 비교**: 다른 기술과의 비교표

### 📈 콘텐츠 구성 비율 (50:50)

```
이론 및 설명 (50%)
├─ 핵심 개념: 20%
├─ 실용적 맥락: 15%
└─ 비교 분석: 15%

코드 및 구현 (50%)
├─ 실습 예제: 25%
├─ 연습 문제: 20%
└─ 참조 자료: 5%
```

## 활용 팁

### 효과적인 사용을 위한 권장사항

1. **명확한 요구사항 제공**
   ```markdown
   ✅ "중급 개발자를 위한 2주 Docker 실무 과정"
   ❌ "Docker 강의 만들어줘"
   ```

2. **단계적 검토**
   - Phase 1-2 완료 후 방향성 확인
   - Phase 3-4 완료 후 콘텐츠 깊이 조정
   - Phase 5-7에서 세부 사항 다듬기

3. **반복적 개선**
   - 파일럿 테스트 결과 반영
   - 학생 피드백 기반 업데이트
   - 기술 변화에 따른 내용 갱신

## 통합 가능한 스킬

이 스킬은 다음 Superpowers 스킬과 연동됩니다:

- `test-driven-development`: TDD 실습 설계
- `systematic-debugging`: 디버깅 교육 콘텐츠
- `code-review`: 코드 리뷰 실습 구성
- `brainstorming`: 교육 내용 구체화

## 품질 지표

성공적인 교안의 기준:
- ✅ 학생 완주율 > 70%
- ✅ 평균 평가 점수 > 75%
- ✅ 만족도 평점 > 4.0/5.0
- ✅ 프로젝트 완성도 > 80%
- ✅ 실무 적용 가능성 확인

## 문제 해결

### 자주 발생하는 이슈

**Q: 생성된 교안이 너무 길어요**
- Phase 단위로 나눠서 생성 요청
- 핵심 모듈만 먼저 상세화

**Q: 실습이 너무 어려워요**
- 난이도 명시: "완전 초보자용"
- 단계별 힌트 추가 요청

**Q: 프로젝트가 복잡해요**
- 미니 프로젝트로 분할
- MVP(최소 기능) 버전부터 시작
